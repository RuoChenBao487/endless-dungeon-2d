# 无尽地牢 2D 版 16.0

> 16.0 新增：亡灵墓穴嵌套房「古代大墓地」「破败教堂」、僵尸与载骨机、
> 三阶段石像鬼、双类型十字架，以及可筛选图鉴和滚动成就页。
> 15.5 在 15.0 的基础上新增：亡灵合体敌人、结算战斗数据与高光、图鉴形象与记录、
> 暂停存档与「继续上一局」、移速/跳跃强化封顶、松键削顶、成就系统。
> 详见「16.0 新增内容」与文末「15.5 新增内容」。

从单文件（14.7.3.py，9789 行）拆成了按职责分层的包结构，同时统一了计时方式、
重做了各生物群系的背景，并加上了跨局保存的冒险记录。

## 运行

```
python main.py
```

存档写在同目录的 `save_data.json`，删掉它等于清空记录。

## 基础重构

**计时统一按帧。** 以前攻击间隔、护盾时长走的是墙上时钟（`get_ticks() // 16`，
隐含假定稳定 60 帧），而房间流程、技能冷却走的是帧计数，掉帧时两者会互相错开。
现在所有计时都走 `timing.frame_count()`，每个循环每轮调用一次 `advance_frame()`。
界面提示仍用毫秒书写，由 `timing.ms()` 在入口处换算成帧。

**背景重做。** 原来每帧重建渐变、粒子、暗角，一帧要九百多次绘制。
现在按生物群系预渲染一张底图并缓存，逐帧只补画会动的部分（火把、火星、气泡、
飘雪、浮尘），并且每个群系有了自己的地貌。

**局外存档。** 新增 `save_data.json`，记录最高层数（总榜与分模式）、累计击杀、
单局最高击杀、总场次、最近五局；设置项（自动射击）也会保存。
结算界面会提示是否刷新纪录，主菜单「冒险记录」页可以查看。

## 改代码时注意

Game 由多个 mixin 组装（见 `game/__init__.py`），方法体保持原样，
所以 `self.xxx` 在任意 mixin 里都能互相访问。新增方法时按职责放进对应的 mixin 即可，
不要忘了它引用的名字要在该模块顶部 import。

## 16.0 新增内容

**古代大墓地。** 亡灵墓穴现在有两种嵌套房，并各自记录是否出现过。每次进入亡灵墓穴房
有 `GREAT_TOMB_ROOM_CHANCE`（0.15）概率变成古代大墓地；出现后区域延长 2 间。
大墓地在地面随机分布 1~3 座墓碑，每座墓碑每 10 秒唤醒一只僵尸。墓碑不是敌人，玩家需要
用子弹或炸弹将其摧毁；大墓地的出口要求敌人清空且墓碑全部破坏。

**僵尸。** 僵尸移动速度只有 `0.55`，血量高、接触伤害低，属于亡灵。僵尸死亡后会
产生幽魂。任何非亡灵在普通僵尸附近死亡时，会额外生成一只僵尸；若附近有巨型僵尸，
则改为额外生成巨型僵尸。额外的僵尸生成和墓穴原本的骷髅生成相互独立，所以会同时
出现。巨型僵尸与巨型骷髅都被标记为精英，并会使用各自的图鉴名称和击杀记录。

首领光环的移动速度增幅可以继续叠加；减伤增幅也可以叠加，但总减伤上限固定为
`60%`。伤害结算会再次夹紧减伤值，并保证最终伤害至少为 1，避免多个光环叠加后
伤害变成负数而给敌人回血。

**载骨机与炼魂魔骷。** 载骨机是古代大墓地的专属精英。附近任何敌人死亡都会为它
回复生命；幽魂和骷髅碰到它时会被直接吸收，并为其回复更多生命。幽魂与普通骷髅各
增加 1 道幽火，巨型骷髅相当于 3 个普通目标，会增加 3 道幽火；累计吸收 5 道后进化
为炼魂魔骷。进化不会清除原有词缀，并追加专属词条「燃魂」。

炼魂魔骷会发射高速幽绿灵魂冲击。灵魂冲击与「燃魂」都走 `Player.take_true_damage()`：
直接扣除生命，绕过护盾、临时生命和普通伤害拦截。燃魂还会让炼魂魔骷自身极慢掉血；
玩家碰到它时会获得持续燃魂，HUD 会显示剩余时间。新增成就「护盾谎言」会在玩家
护盾仍开启时被炼魂魔骷的真实伤害杀死后解锁。

**图鉴与成就界面。** 图鉴现在可以按「普通敌人 / 精英敌人 / BOSS / 特殊」以及
「通用 / 普通地牢 / 冰晶 / 熔岩 / 腐沼 / 墓穴 / 雪山 / 寺庙 / 教堂 / 大墓地」
组合筛选，并可用滚轮、上下键和鼠标浏览全部条目。成就页不再把所有条目挤在一页，
改为左侧可滚动列表、右侧详情与进度条。

**破败教堂。** 亡灵墓穴生态现在拥有一个嵌套房池。进入亡灵墓穴房间时有
`CHURCH_ROOM_CHANCE`（0.15）概率变成破败教堂；每段连续生态中教堂最多出现一次，
出现后区域延长 `CHURCH_REGION_EXTRA`（2）间。教堂不会被抽成事件房，也不会出现在
领主房。场景包含塌落穹顶、残彩窗、长椅、碎石和暗红石台。

**血族敌人。** 新增血仆与血蝙蝠。两者都是亡灵、都会飞行或高速追击，并自带
“吸血”词缀。吸血鬼是教堂的必刷精英，受伤时会每 8 帧抽取附近血仆或血蝙蝠的生命，
等量治疗自己；被抽干的血族原地转化为新的血仆。吸血鬼还会每 6 秒随机召唤血仆或
血蝙蝠。血族之外的单位不能成为抽取目标。

亡灵的死亡规则也同步收紧：墓穴与教堂中只有**非亡灵**死亡才会生成骷髅；
亡灵潮模式中，除幽魂外的任何亡灵死亡都会生成幽魂。血仆、血蝙蝠、骷髅、幽灵和
魔魂亡骨都通过 `is_undead` 标记，相关逻辑在 `game/combat.py` 与
`game/events.py`。

**石像鬼。** 教堂必定刷一只石像鬼精英。初始为灰色石像，不移动也不造成接触伤害；
第一条血条打空后进入青色地面追击阶段；第二阶段血条打空后重新石化，从接近零开始
持续回血，此时可以彻底击杀；如果放任它回满，则进入第三个飞行阶段。实现位于
`entities/enemies.py` 的 `GargoyleEnemy`。

**双类型十字架。** 教堂固定生成两座调查前外观相同的石十字架，靠近按 F 才会揭示
真身。血腥十字架是精英级实体，不直接攻击，持续随机召唤亡灵，并用与巨魔狂呼者
相同的增幅强化半屏内敌人；离开范围后增幅很快消失。圣光十字架缓慢治疗玩家，并每
0.5 秒灼烧附近所有敌人。两者都有精英标准血量，但伤害来源完全分开：血腥十字架
只接受玩家伤害，敌人接触、敌方投射物与圣光范围伤害都不会作用于它；圣光十字架
只接受敌人伤害，玩家子弹和炸弹会直接穿过。十字架状态（隐藏/激活、血量、召唤计时）
进入暂停存档。

## 15.5 新增内容

**亡灵合体：魔魂亡骨。** 幽灵与骷髅撞在一起会合体成一个新敌人（`enemy_type = 13`）。
它继承双方的全部词缀，血量按两者之和的 85% 计算；对玩家的普通攻击与技能攻击
各减伤 50%，但炸弹、灼烧与反伤不打折；附近有骷髅、大骷髅或幽灵倒下时会回一部分血。
巨型骷髅不会参与合体。逻辑在 `game/combat.py` 的 `update_undead_fusion()` /
`_fuse_wraithbone()` / `_heal_nearby_wraithbones()`，画法在
`entities/enemies.py` 的 `_draw_wraithbone()`，配置在 `data/enemies.py`。

**结算战斗数据与高光。** 每局记录伤害构成（普攻 / 技能 / 炸弹与灼烧 / 反伤与盟友）、
承伤来源排行、最高单次伤害、无伤房间数，以及自动生成的高光（终结领主、致命一击、
残血逃生、爆发、滴水不漏）。结算界面左栏是本局概况，右栏是战斗数据；
最近一局的数据也会写进存档，在主菜单「冒险记录」里能看到。
统计入口是 `stats.py` 的 `RunStats`，玩家受伤统一走 `game/combat.py` 的 `hurt_player()`。

**图鉴形象与记录。** 图鉴里现在能看到敌人的样子：形象是拿现有的敌人工厂
（`Enemy` / `EliteEnemy` / `create_boss`）现场生成并放大缓存的，敌人画法一改图鉴跟着变。
每个条目还记录「击杀数」与「被它打死几次」，存在存档的 `codex` 字段里；
菜单与暂停界面共用 `gallery.py` 里的同一份条目表与绘制函数，不再各写一份。
列表在条目变多后会自动滚动，词缀对照表改成两列排布。

存档结构升到 v2：新增 `codex`（图鉴统计）与 `last_run`（最近一局数据），
旧存档读取时会自动补齐这两项，原有纪录不受影响。

**暂停存档与「继续上一局」。** 游戏中按 ESC 暂停后按 S，会把整局现场写进
`run_save.json`，回到主菜单；主菜单第一项「继续上一局」可以原样接着打，
关掉程序再启动也照样能续。存下来的是完整现场：玩家血量与技能、场景里的敌人
（含词缀实例与血量）、领主、投射物与陷阱、房间进度、诅咒、强化次数、战斗统计，
连贴图都按原样带回来，所以恢复后的画面和暂停那一刻一致。
实现是通用快照（`savegame.py`）：遍历所有精灵组，把字段编码成 JSON，
指向别的精灵的引用存成编号、读档时接回去；贴图以 PNG 内联在存档里。
因此以后新增敌人或投射物不用再改存档代码。写盘用「先写临时文件再替换」，
避免写一半崩掉把存档写坏；角色阵亡时存档会自动清掉。

**移速与跳跃封顶。** 这两项各拿满 3 次后就不再出现在奖励池与商店里
（`LIMITED_ENHANCE_PICKS`，计数记在 `Game.enhance_counts`）。

**松键削顶。** 跳跃不再是固定高度：上升过程中松开跳跃键，上冲速度会乘上
`JUMP_CUT_FACTOR`（0.45），于是轻点小跳、长按高跳。这样跳跃高度强化拿多了
也不会破坏落点，精确踩平台重新回到玩家手里。

**成就系统。** 27 条成就，主菜单「成就」页可以看进度（★/☆ 与 已完成/目标）。
大部分成就从已经记下的数据算出来：跨局的在存档里（层数、总击杀、图鉴击杀与阵亡、
各模式最好成绩），单局的在最近一局记录里（单局击杀、精英击杀、无伤房间、最高单次、
伤害构成占比）。「护盾谎言」这类需要特定死亡状态的成就，由本局摘要额外记录标记。
加一条普通成就通常只要往
`achievements.py` 的表里写一行。结算界面会提示本局解锁了哪些。

**鼠标操作。** 主菜单与所有子界面都支持鼠标：主菜单与模式列表悬停即选中、
单击执行；图鉴列表、奖励说明分类、设置项单击即切换；规则与更新日志可用滚轮滚动。
每个子界面左上角都有「返回」按钮（`utils.py` 的 `draw_back_button` / `back_hit`），
游戏内暂停时的规则、图鉴、奖励说明与商店页同样有返回按钮。
所有可点区域的坐标都由一组排版函数给出（例如 `gallery.list_row_rect`、
`utils.reward_cat_rect`），绘制与点击判定共用同一套数字，避免点偏。

**生态区域制。** 生态不再每间随机：一个区域持续 `REGION_ROOMS_MIN`~`MAX`（3~5）
间房，往左回走也算；区域走完后的下一间**必定**是普通地牢，之后每间"继续是普通"
的概率按 `NORMAL_GAP_START`（0.9）依次减 0.1，直到新区域开始。领主房沿用当前
区域的生态（第 10 层的首位领主仍是普通地牢）。规则都在
[regions.py](dungeon/game/regions.py)
的 `_pick_scene_type()` 里。

**暴雪山脉。** 地面用 `build_snow_ground()` 铺成连续起伏的几段；每 30 秒刮一次
持续 6 秒的暴风雪，期间按 `BLIZZARD_PUSH` 把玩家横向推走（直接位移，不会被输入
覆盖），背景加一层飞雪遮挡视野；风雪停后在地上与不高的平台上生成"疏雪层"
（`SnowDrift`，压在角色之上挡视线，被玩家走过或任何爆炸波及就消失）。
敌人：风灵（不造成伤害，只推人）、冰爪狼（精英，`_skill_leap` 扑击，上升阶段
无视平台）、三种巨魔精英（士兵/猎手/狂呼者，都带"再生"词缀，狂呼者每 15 秒给
半屏内的敌人加 5 秒增幅，脚下画红环）。领主是巨雪怪（滚动、跳砸、掀暴风雪；
结霜期间火焰伤害翻倍，由 `adjust_incoming()` 实现）与巨魔酋长（横扫、跳砸、
召唤巨魔士兵、狂呼）。

**暴云寺庙。** 它不是独立生态，而是雪山区域里的一种房间：每进一间雪山房有
`TEMPLE_ROOM_CHANCE`（0.2）概率变成寺庙，出现寺庙会让雪山区域再延长
`TEMPLE_REGION_EXTRA`（3）间，所以越深越可能撞见。寺庙里没有风雪与落雪。
场地上的金色菱形水晶（`StormCrystal`）只刷在最低的平台上，靠近按 F 点亮：
锁定最近的敌人射出光束，每秒伤害为玩家当前攻击力的 `CRYSTAL_DAMAGE_RATE`（2）倍，
持续 4 秒后进入 20 秒冷却（暗淡并显示进度环）。
